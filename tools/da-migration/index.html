DA Content Migration

Copy existing content from DA storage (admin.da.live) to the API Service (api.aem.live). Migrate a site in place, or copy it to a different destination site.

    Pick site

    Select the site whose DA content you want to migrate.

    Leave unchecked to migrate this site in place: content is copied to the API Service, then the site's content source URL is switched.

    Destination site

    Provide the destination site. It must be in the same organization as the source site. If it doesn't exist yet, it will be created.

    How do I get this token?
    1. Sign in to da.live.
    2. Open developer tools (⌘⌥I / Ctrl+Shift+I).
    3. Go to Application → Storage → Cookies → https://da.live.
    4. Find the auth_token cookie and copy its value.
    5. Paste the value into the field above.
